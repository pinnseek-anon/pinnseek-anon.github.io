Data, code and reproduction

The framework, the task packages of the 18 problems and the 30 generalization cases, the discovered PINN solvers, the literature base, the records of the analysed discovery runs and the source data of the figures. 29 files, 274.4 MB in total, each a zip archive with a README and the md5 of every file inside.

Reproduce a result of Table 1

Every discovered solver follows the task contract and runs with the evaluation tool of its task package, which trains it for the training time of the problem and prints its relative L2 error. The evaluation tool uses POSIX file locks, so it runs on Linux with one NVIDIA GPU; the paper uses an RTX A6000, and the error reached in a fixed wall-clock time depends on the GPU.

# packages pinned in pyproject.toml of the framework
python3.11 -m venv .venv && . .venv/bin/activate
pip install "jax[cuda12]==0.4.33" flax==0.9.0 optax==0.2.3 numpy==2.1.1 scipy==1.17.1 \
            jaxopt==0.8.5 ml_collections==1.1.0 \
            "soap-jax @ git+https://github.com/haydn-jones/SOAP_JAX@ddddc25724dfd629b0cd01584eca1e32ea8ac4de"

# a task package and its discovered solver, e.g. KS
unzip task-ks.zip && unzip discovered-solvers.zip
mkdir -p project/blocks/b01
cp -r task-ks/ks project/task
cp discovered-solvers/ks.py project/blocks/b01/
cd project && python task/eval.py blocks/b01/ks.py --gpu 0 --seed 1   # seeds 1-5 as in Table 1

The last line printed is the evaluation record, with the relative L2 error of Table 1, ‖u − uref‖2 / ‖uref‖2 on the reference grid, with the fields of each problem as defined in Supplementary Note 1. --smoke runs a 10-second rehearsal on the CPU.
