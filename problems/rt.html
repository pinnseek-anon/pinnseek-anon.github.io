Problem definition

The Boussinesq equations for the velocity $(u,v)$, the pressure $p$ and the temperature $T$, which enters the vertical momentum equation as a buoyancy force, \[ \begin{aligned} \pd{u}{t}+u\,\pd{u}{x}+v\,\pd{u}{y}&=-\pd{p}{x}+\sqrt{\frac{\mathrm{Pr}}{\mathrm{Ra}}}\left(\pdn{2}{u}{x}+\pdn{2}{u}{y}\right),\\ \pd{v}{t}+u\,\pd{v}{x}+v\,\pd{v}{y}&=-\pd{p}{y}+\sqrt{\frac{\mathrm{Pr}}{\mathrm{Ra}}}\left(\pdn{2}{v}{x}+\pdn{2}{v}{y}\right)+T,\\ \pd{u}{x}+\pd{v}{y}&=0,\\ \pd{T}{t}+u\,\pd{T}{x}+v\,\pd{T}{y}&=\frac{1}{\sqrt{\mathrm{Pr}\,\mathrm{Ra}}}\left(\pdn{2}{T}{x}+\pdn{2}{T}{y}\right), \end{aligned} \] with the Prandtl number $\mathrm{Pr}=0.71$ and the Rayleigh number $\mathrm{Ra}=10^6$, so $\sqrt{\mathrm{Pr}/\mathrm{Ra}}=8.426150\times10^{-4}$ and $1/\sqrt{\mathrm{Pr}\,\mathrm{Ra}}=1.186782\times10^{-3}$, hold on $(t,x,y)\in[0,4.75]\times[0,1]\times[0,2]$. The fields are periodic in $x$ with period 1, \[ \pdn{n}{q}{x}(t,0,y)=\pdn{n}{q}{x}(t,1,y),\qquad q\in\{u,v,p,T\},\ n=0,1,2,\ldots, \] and $u=v=T=0$ on the bottom and top walls $y=0$ and $y=2$. The initial fields $u(0,x,y)$, $v(0,x,y)$ and $T(0,x,y)$ are the reference solution at $t=0$ on a non-uniform $100\times200$ grid, in which a layer with $T\approx1$ lies below a layer with $T\approx0$ and a perturbed interface near $y=1$ separates them. The error is measured on $T$ at the 20 times $t=0,0.25,\ldots,4.75$ on the same grid. The problem is the interval $[1.01,5.76]$ of the Rayleigh–Taylor flow released with APTS  (Wang et al., 2026), shifted to start at $t=0$, and its reference solution is that flow, which APTS computes with the Julia package IncompressibleNavierStokes.jl.
